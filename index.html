What I have built

Major project · Team of three

SmartBinX

IoT + AI waste classification

A smart bin that identifies the type of waste put into it and sorts it automatically. It pairs low-cost sensors and a camera with an on-device machine-learning model, so classification does not depend on a server.

I also explored how this could be deployed in India, including government-ready enhancements aligned with Swachh Bharat and the Smart Cities Mission. Documentation covers the SRS, project report, synopsis and presentation.

  • TensorFlow Lite
  • ESP32-CAM
  • Arduino Uno
  • IoT
  • Computer vision
Code https://smartbinx-dx5q.onrender.com

How it works

    IR sensor detects that an item has been dropped in.
  1. ESP32-CAM captures an image of the item.
  2. TensorFlow Lite model classifies the waste type.
  3. Servo motors route the item to the right compartment.
  4. HC-SR04 ultrasonic sensor tracks how full the bin is.
